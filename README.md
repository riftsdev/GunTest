# GunTest FPS

Protótipo de campo de tiro 3D em HTML e Three.js.

## Jogar

Abra `index.html` em um servidor web (ou habilite GitHub Pages para a branch `main`, pasta `/`). O jogo precisa de internet para importar Three.js.

## Controles

WASD: andar; mouse: mirar (Pointer Lock); clique esquerdo: atirar; R: recarregar; Shift: correr; Espaço: pular; ESC: menu. Todos os controles podem ser remapeados no menu, inclusive o botão de disparo. Ajuste a sensibilidade no menu.

## Funcionalidades

Arma 3D procedural, alvos reativos com respawn, caixa com física simplificada (gravidade, impulso e atrito), colisões de cenário, munição, recarga, recoil e Mouse Lock.

## Observações

Esta versão publicada foi desenvolvida para teclado e mouse no PC. A física não utiliza motor rígido completo. O pacote ZIP fornecido separadamente inclui uma versão expandida e o modelo GLB de braços fornecido pelo usuário, que ainda não foi enviado ao repositório.
